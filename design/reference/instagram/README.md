# Instagram reference screenshots (you capture these)

The Instagram shell in the app must match the **current** Instagram iOS app, and screenshots are the only reliable source. Take these on your iPhone (dark mode, same iPhone model you'll demo on), save as PNG with these exact names, and drop them in this folder before Step 7.

| File | What to capture |
| --- | --- |
| `01-home.png` | Home feed at the top: top bar (+, wordmark, heart), story tray, first post header and image, tab bar |
| `02-home-post-full.png` | One full feed post: header, image, action row, likes line, caption, timestamp |
| `03-story-tray-closeup.png` | Zoomed story tray: your story with +, unseen ring, seen ring, Close Friends ring if you have one |
| `04-tab-bar-selected-states.png` | Tab bar with each tab selected (5 screenshots ok: `04a`…`04e`) |
| `05-story-viewer.png` | Viewing a friend's Story: progress bars, header, bottom reply bar |
| `06-story-viewer-paused.png` | Same Story while holding to pause (chrome hidden) |
| `07-story-link-sticker.png` | A Story with a link sticker |
| `08-post-detail.png` | Opening a single post from a profile grid |
| `09-share-sheet.png` | Instagram's own share sheet on a post |
| `10-story-composer.png` | The Story composer after sharing an image into Instagram |
| `video-story-open-close.mov` | Screen recording: open a Story from the tray, tap through, swipe down to close (for motion timing) |

Tips: crop nothing, keep the status bar, and turn off notifications while capturing.
